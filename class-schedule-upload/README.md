# Refreshing class data

1. Download the Schedule of Classes CSV for the term.
2. Name it with the term, for example `Spring_2027_Schedule_of_Classes.csv`.
3. On github.com, open this folder, choose **Add file > Upload files**, drop in the CSV, and click
   **Commit changes**.

A GitHub Action converts it, removes the CSV from this folder, and publishes the new class data
within a few minutes. Students see "Sections as of" the upload date. Check progress under the
repository's **Actions** tab ("Refresh class data").

Good times to refresh: just before registration opens, and after each class standing's
enrollment window.
